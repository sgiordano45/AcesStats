Historical game import

Load a team's old game-by-game batting lines (AB, H, R, BB). They show on each player's Splits tab only: home vs away, regular season vs playoffs, by opponent, and the game log. Season totals, leaders and badges are not touched. Loading the same games again replaces them.

1. Team and file

Columns: Date, Opponent, HomeAway, GameType, Player, AB, H, R, BB. HomeAway is H or A. GameType is Regular or Playoff (blank means Regular). An optional Season column (Summer or Fall) overrides the season worked out from the date (September on is Fall). An optional GameNum column separates doubleheaders.

2. Match players

Each name in the file, matched to a player record. Fix any that are wrong or not found. The numbers are the file's totals next to the player's stored season totals.
