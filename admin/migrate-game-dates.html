Fix game dates

Some game dates were saved as a plain map instead of a Firestore Timestamp. A map sorts after every Timestamp, which can scramble date order. This converts them in place. Only the date field changes; nothing else on the document is touched.

Where it looks

Every player's batting and pitching game docs (playerStats, pitchingStats), the date fields on hitStreaks (startDate, endDate, currentStreakStart) and careerHighs (gameDate).
